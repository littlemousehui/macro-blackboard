要多少資本才夠？企業在權衡什麼

企業用資本、勞動和其他資源生產，目標是利潤最大化。每多買一台機器之前，都要放上天平秤一秤：

⚖️ 左盤：好處

資本的邊際產出（MPK）

每多投入一單位資本，能多生產多少

⚖️ 右盤：成本

資本的租賃成本（rc）

每多使用一單位資本，要付出多少

好處 > 成本 → 繼續買；好處 < 成本 → 停手。

權衡：增加資本帶來的營收（資本的邊際產量）vs 取得額外資本的成本。

最適資本存量：MPK = rc

資本愈多，多一台機器帶來的產出愈少（邊際產出遞減）。

企業會一直加資本，直到：

最後一單位的 MPK = rc

租賃成本從 rc0 升到 rc1 → 要更高的邊際產出才划算 → 資本降到 K1*。

成本愈高，想要的資本愈少

企業持續增加資本，直到最後一單位 MPK = rc；資本邊際產量遞減。

K* = g(rc, Y)：兩個旋鈕

K* = g(rc, Y)

🎛️ 旋鈕一：租賃成本 rc

利率↑、預期通膨↓、折舊↑ → rc↑ → K* ↓

🎛️ 旋鈕二：產出 Y

需求愈多、要生產愈多 → 需要更多機器 → K* ↑

任何讓 K* 上升的因素，都會讓投資增加

K*＝最適資本存量；rc＝租賃成本；Y＝產出。

需求增加後：短期 vs 長期

(a) 資本需求：DD₀ → DD₁

(b) 投資流量：價格愈高，投資愈多

⚡ 短期

資本存量來不及變 → 資本價格 P0 飆到 P1 → 投資從 I0 增加到 I1

🐢 長期

資本供給很有彈性 → 價格回到 P0，但資本已經從 K0 變成 K1

I₀ 足以抵消資本的折舊（維持現有存量）；短期內資本存量固定，會先推升資本的價格，使投資流量增加。

你的四步驟筆記

第 11 張是你自己整理的，寫得很清楚，直接搬上黑板：

① 需求增加：引發了對更高資本存量（K₁）的需求。
② 價格短期飆升：因為資本存量調整緩慢，短期內供需失衡導致成本（租賃價格）上升。
③ 投資填補缺口：為了縮小現有資本與理想資本之間的差距，企業產生了額外的投資流量（I₁）。
④ 長期回歸：隨著投資不斷注入，資本存量增加，稀缺性降低，價格（成本）最終回歸平穩。

第 ③ 步的「缺口」有多快補上？下一頁。

彈性加速模型：每期補一部分缺口

K0 = K−1 + λ(K* − K−1)
I = λ(K* − K−1)
  • K−1：上一期期末的資本
  • K*：想要的資本
  • λ：每期補上缺口的比例（速度）

缺口愈大，投資愈多

推論（非簡報原文）：數位需求讓預期產出 Y↑、新技術讓 MPK↑ → 台積電的 K* 大幅上升 → 缺口很大 → 好幾年的大規模投資。

五個重點

  1. 投資是流量，資本是存量
  2. rc = i − πe + δ
  3. MPK = rc 決定 K*
  4. I = λ(K* − K−1)
  5. 企業固定投資最大，存貨投資波動最大

常見誤解

  • ❌ 投資和資本是同一個東西
  • ❌ 租賃成本看名目利率就好
  • ❌ K* 不變，投資也不會變小
  • ❌ 住宅投資和利率沒關係

這條推論鏈，就是第 13 章 IS 曲線裡 I(i) 的由來：利率↓ → 投資↑。
