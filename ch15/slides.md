## P05 流量 vs 存量
- **版型**：雙欄＋比喻
- **重點**：投資是流量、資本是存量
- **內容要點**：投資理論＝資本需求理論；資本＝某一時點所有建築、機器、存貨的價值（存量）；投資＝一段期間內為增加資本存量的支出（流量）；GDP 也是流量；投資流量和資本存量相比很小
- **比喻**：🛁 浴缸：水位＝資本、水龍頭＝投資、排水口＝折舊（補充比喻）
- **📝**：投資理論＝資本需求理論；為了增加資本存量支出的流量；投資是流量；資本是存量
- **出處**：[流量與存量](../wiki/concepts/%E6%B5%81%E9%87%8F%E8%88%87%E5%AD%98%E9%87%8F.md)（來源第 5 張）

## P06 要多少資本才夠？企業在權衡什麼
- **版型**：天平
- **重點**：好處是多一台機器多生產多少，成本是多用一台機器要付多少
- **內容要點**：企業用資本、勞動和其他資源生產，目標是利潤最大化；左盤：資本的邊際產出（MPK）＝每多投入一單位資本能帶來多少額外產出；右盤：資本的租賃成本（rc）＝每多使用一單位資本要付出的成本
- **比喻**：⚖️ 天平
- **📝**：權衡：增加資本帶來的營收（資本的邊際產量）vs 取得額外資本的成本；每多投入一單位資本能帶來多少額外產出；每多使用一單位資本要付出的成本
- **出處**：[最適資本存量](../wiki/models/%E6%9C%80%E9%81%A9%E8%B3%87%E6%9C%AC%E5%AD%98%E9%87%8F.md)（來源第 6 張）

## P07 用一台機器要花多少？租賃成本
- **版型**：公式＋拆解
- **重點**：租賃成本＝實質利率＋折舊率
- **公式**：$rc = r + \delta = i - \pi^e + \delta$
- **內容要點**：① 借錢買機器，利率 i ② 有通膨時機器的名目價值會上升 ③ 決定時明年通膨未知 → 用預期通膨 π^e ④ 機器會耗損 → 加折舊率 δ；🔣 簡報寫 d，wiki 用 δ
- **比喻**：租一台機器：付利息（扣掉機器漲價）＋一年的磨損（補充比喻）
- **📝**：名目利率；實質利率；資本折舊率
- **出處**：[資本的租賃成本](../wiki/concepts/%E8%B3%87%E6%9C%AC%E7%9A%84%E7%A7%9F%E8%B3%83%E6%88%90%E6%9C%AC.md)（來源第 7 張）

## P08 實質利率：扣掉通膨才是真成本
- **版型**：公式＋例子
- **重點**：r = i − π^e
- **內容要點**：i 名目利率、π^e 預期通膨、r 實質利率；做投資決定時，名目利率已知、明年通膨未知；🔣 r（實質利率）和第13章的 R（實質匯率）不同
- **例子**：房貸 5%、預期通膨 2% → 實質約 3%（補充例子）
- **出處**：[實質利率與預期通膨](../wiki/concepts/%E5%AF%A6%E8%B3%AA%E5%88%A9%E7%8E%87%E8%88%87%E9%A0%90%E6%9C%9F%E9%80%9A%E8%86%A8.md)（來源第 7 張）

## P09 最適資本存量：MPK = rc
- **版型**：圖表＋說明
- **重點**：一直加資本，到最後一單位的邊際產出等於租賃成本；成本上升 → K* 下降
- **內容要點**：資本邊際產出遞減；租賃成本從 rc₀ 升到 rc₁ → 需要更高的邊際產出才划算 → 資本降到 K₁*
- **視覺**：`mpk`：MPK 遞減曲線＋rc₀、rc₁ 水平線，交點 K₀*、K₁*（仿第 8 張）
- **📝**：企業持續增加資本，直到最後一單位 MPK = rc；資本邊際產量遞減
- **出處**：[最適資本存量](../wiki/models/%E6%9C%80%E9%81%A9%E8%B3%87%E6%9C%AC%E5%AD%98%E9%87%8F.md)、[邊際報酬遞減](../wiki/concepts/%E9%82%8A%E9%9A%9B%E5%A0%B1%E9%85%AC%E9%81%9E%E6%B8%9B.md)（來源第 6、8 張）

## P10 K* = g(rc, Y)：兩個旋鈕
- **版型**：雙卡片
- **重點**：租賃成本↑ → K*↓；產出↑ → K*↑
- **公式**：$K^* = g(rc, Y)$
- **內容要點**：旋鈕一：租賃成本（利率、通膨預期、折舊）；旋鈕二：產出（需求愈多要愈多機器）；任何讓 K* 上升的因素都會提高投資
- **📝**：最適資本存量；租賃成本；產出
- **出處**：[最適資本存量](../wiki/models/%E6%9C%80%E9%81%A9%E8%B3%87%E6%9C%AC%E5%AD%98%E9%87%8F.md)、[投資的決定因素](../wiki/synthesis/%E6%8A%95%E8%B3%87%E7%9A%84%E6%B1%BA%E5%AE%9A%E5%9B%A0%E7%B4%A0.md)（來源第 8、14 張）

## P11 需求增加後：短期 vs 長期
- **版型**：雙圖＋步驟
- **重點**：短期資本價格先飆、投資增加；長期價格回落、資本變多
- **內容要點**：起點 K₀、P₀，投資 I₀ 剛好抵消折舊；需求增加 DD₀ → DD₁；短期資本存量固定 → 價格 P₀ → P₁ → 投資 I₀ → I₁；長期資本供給有彈性 → 價格回到 P₀，資本存量 K₀ → K₁
- **視覺**：`dd`（資本需求 DD₀、DD₁ 與 P₀、P₁）＋`invflow`（投資流量曲線，I₀、I₁）
- **📝**：足以抵消資本的折舊（維持現有存量）；短期內資本存量固定，會先推升資本的價格，使投資流量增加
- **出處**：[最適資本存量](../wiki/models/%E6%9C%80%E9%81%A9%E8%B3%87%E6%9C%AC%E5%AD%98%E9%87%8F.md)（來源第 9–10 張）

## P12 你的四步驟筆記
- **版型**：四格流程（便利貼）
- **重點**：需求增加 → 價格短期飆升 → 投資填補缺口 → 長期回歸
- **📝**（第 11 張全文）：① 需求增加：引發了對更高資本存量（K₁）的需求 ② 價格短期飆升：因為資本存量調整緩慢，短期內供需失衡導致成本（租賃價格）上升 ③ 投資填補缺口：為了縮小現有資本與理想資本之間的差距，企業產生了額外的投資流量（I₁）④ 長期回歸：隨著投資不斷注入，資本存量增加，稀缺性降低，價格（成本）最終回歸平穩
- **出處**：[最適資本存量](../wiki/models/%E6%9C%80%E9%81%A9%E8%B3%87%E6%9C%AC%E5%AD%98%E9%87%8F.md)（來源第 11 張）

## P13 彈性加速模型：每期補一部分缺口
- **版型**：公式＋例子
- **重點**：缺口愈大，投資愈多
- **公式**：$K_0 = K_{-1} + \lambda(K^* - K_{-1})$；$I = K_0 - K_{-1} = \lambda(K^* - K_{-1})$
- **內容要點**：K₋₁ 上期期末資本、K* 期望資本、λ 每期補上缺口的比例
- **例子**：λ = 0.5、K* = 100、K₋₁ = 60 → 投資 20、10、5……（補充例子）
- **📝**：彈性加速模型解釋企業調整資本存量的速度；越大越快；K₀ = K₋₁ + I；速度 λ
- **出處**：[彈性加速模型](../wiki/models/%E5%BD%88%E6%80%A7%E5%8A%A0%E9%80%9F%E6%A8%A1%E5%9E%8B.md)（來源第 12–13 張）
