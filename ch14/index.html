原因：現在花多少，和「預期未來會花多少」緊緊相連（第 15 頁再談）。

凱因斯：賺多少，花一定比例

C = C̄ + c·YD
  • C̄：自發性消費（沒收入也要花的）
  • c：MPC，介於 0 和 1 之間
  • YD：這一期的可支配所得

早期凱因斯理論：這一期花多少，看這一期賺多少。

盲點：不區分「一次性」和「長期」的所得。
🔣 這裡的小寫 c 是 MPC，和第 3 章的人均消費不同。

生命週期理論：人會在很長的期間規劃消費和儲蓄，想在一生中做最好的分配。

關鍵假設：消費平滑化

  • 多數人喜歡穩定的生活方式
  • 不喜歡消費每年大起大落
  • 最簡單的版本：每年花一樣多

所以對「長期所得」「一次性所得」「財富」，會有不同的 MPC。

一生能吃的蛋糕就這麼大。與其年輕時一口吞掉、老了沒得吃，不如切成 60 等份，每年吃一片。

C = WLNL × YL

WL＝工作年數　NL＝一生年數　YL＝每年勞動所得（🔣 WL、NL 是一個符號，不是相乘）

NL＝從開始工作到死亡的時間。

儲蓄與財富的一生

有了消費理論，就有儲蓄理論：S = Y − C

  • 工作期：所得 > 消費 → 存錢（圖中「儲蓄」）
  • 退休期：所得 = 0 < 消費 → 動用存款（負儲蓄）
  • 財富在退休那年最高
  • 財富在過世時歸零
S = Y − C；工作期所得 > 消費，退休期所得 < 消費。

為什麼？因為一筆財富也會攤到剩下的人生慢慢花。

這個 MPC 可以用來把資產價值的變化（股價、房價）連到現在的消費。

🎰 樂透獎金切成小份

中了一大筆錢，不會一次花光，而是切成很多小份，餘生每年多花一點。

（比喻為補充）

一次性財富增加；平滑原則，不會一次花掉。

Friedman 的恆常所得理論

C = c · YP

恆常所得 YP 是什麼？

在目前的財富、現在和未來的所得給定下，這輩子可以一直維持的穩定支出水準。

和生命週期理論的關係

都說：消費不看這一期賺多少，而看長期能賺多少。
兩者合稱 PILCH（恆常所得－生命週期假說）。

恆常可支配所得。

Hall：消費只因驚喜而改變

Ct+1 = Ct + ε

明天的消費 ＝ 今天的消費 ＋ 真正隨機的誤差 ε

📅 預料中的加薪

早就知道明年會加薪 → 今年已經照「加薪後的收入」在花 → 明年真的加薪時，消費不會再跳。

🎁 意外的升遷或裁員

沒料到的事才會改變你對長期所得的估計 → 消費才會改變。

例子為補充。傳統 PILCH：恆常所得已知就永遠不變；Hall 的版本加入了「所得不確定」。

傳統 PILCH 每期消費水準都相同。

為什麼理論只對一半？

🔒 流動性限制

預期未來收入會變高，但現在借不到錢。

→ 沒辦法照理論預測的較高水準消費
→ 消費更緊跟著當期所得

例：剛出社會、前景看好但借不到錢的年輕人（補充）

👓 短視

消費者沒有理論假設的那麼會為未來打算。

流動性限制；短視。

為什麼老人不花光存款？

生命週期理論說「退休後花光存款」，但現實中老年人很少動用存款，多半靠利息、股利生活。因為還有其他儲蓄動機：

👨‍👩‍👧 留遺產

存錢留給子女：可能是利他動機，也可能是策略動機。

🏥 預防性儲蓄

防範意外事件，例如醫療費用。不確定愈大，存得愈多。

緩衝儲備儲蓄；留遺產。

總整理：四種消費理論

理論消費取決於式子MPC
凱因斯消費函數這一期的所得C = C̄ + c·YD單一、高
生命週期理論一生的資源C = (WL/NL)·YL恆常 0.75／暫時 0.017
恆常所得理論（Friedman）恆常所得C = c·YP對恆常所得
隨機漫步（Hall）上期消費＋意外Ct+1 = Ct + ε只對意外反應
凱因斯：賺多少，花一定比例。
生命週期／恆常所得：看一輩子能賺多少，再平均花。Hall：只因驚喜而改變。

回到消費券：理論怎麼說？

理論消費券是什麼預測效果
凱因斯當期所得增加大（MPC 高）
生命週期／恆常所得一次性的暫時所得小（MPC ≈ 0.017）
流動性限制借不到錢家庭的救急錢這群人效果較大
還有一件事：如果你本來就會花這筆錢，消費券只是替代了原本的現金，總消費不一定增加。
實證：台灣只有約 1/4 用在計畫外消費、南韓只有 36% 家庭多花錢 → 比較接近 PILCH 的預測。

重點回顧＋常見誤解

五個重點

  1. 消費占總需求約 70%，而且比 GDP 穩定
  2. 凱因斯：消費看當期所得，只有一個 MPC，而且偏高
  3. 生命週期：恆常所得 MPC 大（0.75），暫時所得 MPC 小（0.017）
  4. Hall：消費只因「意外」而改變
  5. 流動性限制、短視、遺產與預防，讓現實偏離理論

常見誤解

  • ❌ MPC 是固定的一個數
  • ❌ 現代理論說人拿到錢什麼都不花
  • ❌ 財富的 MPC 和恆常所得一樣大
  • ❌ 發消費券一定能刺激消費
