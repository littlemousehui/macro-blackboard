# 大綱：第14章 消費與儲蓄

## 故事線
**貫穿問題**：「政府發你一筆消費券，**你會多花多少？**」
答案取決於「多拿一塊錢會花掉多少」——邊際消費傾向（MPC）。先看消費的特性，再依序比較四種消費理論對 MPC 的看法，最後回到消費券，用理論解釋為什麼台灣、南韓的消費券效果有限。

```mermaid
flowchart LR
  A[開場<br/>消費券有用嗎] --> B[第一部<br/>消費的特性] --> C[第二部<br/>凱因斯：MPC 高] --> D[第三部<br/>生命週期・恆常所得] --> E[第四部<br/>現代理論與現實] --> F[收尾<br/>回到消費券]
```
