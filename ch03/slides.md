## P02 一個真實故事：阿根廷

- **重點**：曾是全球成長最快的國家，一百年後人均所得只剩美國的三分之一左右
- **內容要點**：

- **視覺**：`line-argentina`（阿根廷/美國人均 GDP 比值，1875–2015，標「目測約值」）

## P03 今天要回答的問題
- **版型**：流程
- **重點**：一個國家的長期生活水準由什麼決定？
- **內容要點**：① 產出從哪裡來（生產函數）→ ② 過去的成長怎麼拆解（成長核算）→ ③ 未來會成長到哪裡（Solow 模型）→ ④ 存多少錢最好（黃金法則）
- **📝**：成長核算是「拆解過去的貢獻」，成長理論是「解釋未來的累積」
- **出處**：[成長核算](../wiki/concepts/%E6%88%90%E9%95%B7%E6%A0%B8%E7%AE%97.md)、[第3章 成長與累積](../wiki/sources/%E7%AC%AC3%E7%AB%A0%20%E6%88%90%E9%95%B7%E8%88%87%E7%B4%AF%E7%A9%8D.md)

## P04 先認識四個符號
- **版型**：四格圖示
- **重點**：用麵包店比喻整個經濟
- **比喻**：🍞 Y 產出＝麵包總量（GDP）；🔥 K 資本＝烤箱、機器；👩‍🍳 N 勞動＝師傅；📖 A 技術＝食譜與做法
- **內容要點**：小寫字母代表「平均每人」，例如 y = Y/N
- **出處**：[生產函數](../wiki/concepts/%E7%94%9F%E7%94%A2%E5%87%BD%E6%95%B8.md)、[glossary](../wiki/glossary.md)

## P05 生產函數：產出從哪裡來
- **版型**：公式＋雙卡片
- **重點**：產出成長只有兩個來源：投入變多、生產力提升
- **公式**：Y = A·F(K, N)
- **比喻**：多買烤箱、多請師傅（K↑、N↑）；食譜改良（A↑）
- **內容要點**：假設 MPN、MPK > 0
- **出處**：[生產函數](../wiki/concepts/%E7%94%9F%E7%94%A2%E5%87%BD%E6%95%B8.md)（來源第 5 張）

## P06 為什麼要看「平均每人」
- **版型**：雙欄
- **重點**：生活水準看人均；人均成長率＝總成長率－人口成長率
- **公式**：y = Y/N、k = K/N；Δy/y = ΔY/Y − ΔN/N
- **例子**：GDP 成長 3%、人口成長 1% → 每人約多 2%
- **內容要點**：k 是每人資本（資本-勞動比）＝每位師傅分到幾台烤箱
- **出處**：[人均 GDP](../wiki/indicators/%E4%BA%BA%E5%9D%87%20GDP.md)（來源第 8 張）

## P07 成長核算：把成長拆開來看
- **版型**：公式＋雙卡片
- **重點**：產出成長＝各投入成長 × 重要性權重＋技術進步
- **公式**：ΔY/Y = (1−θ)ΔN/N + θΔK/K + ΔA/A
- **內容要點**：θ＝資本拿走的所得比例；例：θ = 0.25 → 25% 給資本、75% 給勞動
- **出處**：[成長核算](../wiki/concepts/%E6%88%90%E9%95%B7%E6%A0%B8%E7%AE%97.md)（來源第 6 張）

## P08 例題：多存機器 vs 多請人
- **版型**：長條圖
- **重點**：資本成長多 3 個百分點，產出只多 0.75 個百分點，因為勞動權重較大
- **內容要點**：θ = 0.25；勞動 1.2%、資本 3%、技術 1.5%
- **視覺**：`bars-growth-accounting`：基準 0.9+0.75+1.5 = 3.15%；資本加倍 0.9+1.5+1.5 = 3.9%；勞動加倍 1.8+0.75+1.5 = 4.05%
- **出處**：[成長核算](../wiki/concepts/%E6%88%90%E9%95%B7%E6%A0%B8%E7%AE%97.md)（來源第 7 張）

## P09 換成「平均每人」的版本
- **版型**：公式＋白話對照
- **重點**：生活水準提升＝每人機器增加＋技術提升
- **公式**：Δy/y = θ·Δk/k + ΔA/A
- **內容要點**：勞動項消失是因為兩邊都扣掉人口成長，不是勞動不重要
- **📝**：左邊是「生活水準提升多少」，右邊是「機器增加多少」加上「技術提升多少」
- **出處**：[成長核算](../wiki/concepts/%E6%88%90%E9%95%B7%E6%A0%B8%E7%AE%97.md)（來源第 9–10 張）

## P10 不只機器：人力資本
- **版型**：雙欄
- **重點**：教育與在職訓練和機器、勞動一樣重要（份額各約 1/3）
- **公式**：Y = A·F(K, H, N)
- **內容要點**：Mankiw、Romer、Weil（1992）；投資率、平均受教育年數都與人均 GDP 正相關（Figure 3-2）；相關不一定是因果
- **出處**：[人力資本](../wiki/concepts/%E4%BA%BA%E5%8A%9B%E8%B3%87%E6%9C%AC.md)（來源第 12–13 張）

## P11 關鍵概念：邊際報酬遞減
- **版型**：雙欄（文＋圖）
- **重點**：資本愈多，多一單位資本帶來的產出愈少
- **比喻**：一位師傅從 1 台烤箱加到 2 台產量大增，加到第 10 台根本顧不過來
- **視覺**：`curve-diminishing`：y = f(k) 加遞減階梯（+0.21、+0.14、+0.12、+0.10）
- **出處**：[邊際報酬遞減](../wiki/concepts/%E9%82%8A%E9%9A%9B%E5%A0%B1%E9%85%AC%E9%81%9E%E6%B8%9B.md)（來源第 16 張）

## P12 Solow 模型的核心想法
- **版型**：流程
- **重點**：每人資本像會漏水的水桶：儲蓄流入、折舊與人口稀釋流出
- **內容要點**：由 Robert Solow 提出的新古典成長模型（大綱檢查提醒：帶出 [梭羅 (Robert Solow)](../wiki/people/%E6%A2%AD%E7%BE%85%20%28Robert%20Solow%29.md)）
- **比喻**：🪣 流入＝儲蓄 sf(k)；流出＝(n+δ)k
- **公式**：Δk = s·f(k) − (n+δ)k；s 儲蓄率、n 人口成長率、δ 折舊率
- **📝**：儲蓄決定投資，投資決定資本
- **出處**：[Solow 新古典成長模型](../wiki/models/Solow%20%E6%96%B0%E5%8F%A4%E5%85%B8%E6%88%90%E9%95%B7%E6%A8%A1%E5%9E%8B.md)、[梭羅 (Robert Solow)](../wiki/people/%E6%A2%AD%E7%BE%85%20%28Robert%20Solow%29.md)（來源第 14、17–18 張）

## P13 水桶為什麼會漏水？損益兩平投資
- **版型**：雙卡片
- **重點**：維持每人資本不變至少要投資 (n+δ)k
- **內容要點**：漏洞一折舊 δk（烤箱會壞）；漏洞二人口稀釋 nk（新師傅要配烤箱）；三個名稱：損益兩平投資、必要投資、維持人均資本恆定所需的投資
- **出處**：[損益兩平投資](../wiki/concepts/%E6%90%8D%E7%9B%8A%E5%85%A9%E5%B9%B3%E6%8A%95%E8%B3%87.md)（來源第 17、19 張）

## P14 穩態：水桶的水位不再變動
- **版型**：圖表＋說明
- **重點**：流入＝流出時 k 停止變動
- **公式**：s·f(k*) = (n+δ)k*
- **視覺**：`solow-base`：f(k)、sf(k)、(n+δ)k，交點 C、D，左右箭頭標「k 增加／k 減少」
- **📝**：資本增加 → 邊際報酬遞減 → 新增的資本只夠抵銷折舊和新增人口 → k 不再增加
- **出處**：[穩態](../wiki/concepts/%E7%A9%A9%E6%85%8B.md)（來源第 14、20 張）

## P15 穩態不是「不成長」
- **版型**：表格＋短文
- **重點**：穩態時人均不變、總產出以 n 成長；條件相同的國家會收斂
- **內容要點**：表格（k、y 成長率 0；Y 成長率 n）；收斂：s、n、技術相同 → 走到同一穩態，但過程可能很慢；例：1950–1973 日本人均 GDP 年成長 8.01%、美國 2.42%（Maddison）
- **📝**：穩態時 Δy = 0，所以 ΔY/Y = ΔN/N = n
- **出處**：[穩態](../wiki/concepts/%E7%A9%A9%E6%85%8B.md)、[收斂](../wiki/concepts/%E6%94%B6%E6%96%82.md)、[人均 GDP](../wiki/indicators/%E4%BA%BA%E5%9D%87%20GDP.md)（來源第 8、11、22 張）

## P16 如果大家更會存錢？（s↑）
- **版型**：圖表＋步驟
- **重點**：所得水準變高，長期成長率不變
- **內容要點**：① 儲蓄曲線上移 ② 原 k* 處流入 > 流出 ③ k 增加到 k**（C′）
- **視覺**：`solow-s-up`：sf(k) 與虛線 s′f(k)，C → C′
- **📝**：s 只能提高所得水準 y，長期成長率由 n 決定；原因是資本邊際報酬遞減
- **出處**：[Solow 新古典成長模型](../wiki/models/Solow%20%E6%96%B0%E5%8F%A4%E5%85%B8%E6%88%90%E9%95%B7%E6%A8%A1%E5%9E%8B.md)（來源第 23 張）

## P17 過渡期：成長只會暫時加速
- **版型**：雙圖
- **重點**：成長率先跳高、再慢慢回到 n
- **視覺**：`path-y`（y* 平滑升到 y**）＋`path-growth`（ΔY/Y 在 t₀ 跳高後遞減回 n）
- **📝**：在過渡期資本快速累積，每人平均產出成長率會增加；最終成長率會回到原本的人口成長率
- **出處**：[Solow 新古典成長模型](../wiki/models/Solow%20%E6%96%B0%E5%8F%A4%E5%85%B8%E6%88%90%E9%95%B7%E6%A8%A1%E5%9E%8B.md)（來源第 24–25 張）

## P18 如果人口成長更快？（n↑）
- **版型**：圖表＋說明
- **重點**：人均所得下降、總產出成長率上升
- **內容要點**：(n+δ)k 變陡；許多開發中國家觀察得到；提醒：s 動的是曲線，n、δ 動的是直線
- **視覺**：`solow-n-up`：(n+δ)k 與虛線 (n′+δ)k，C → C′
- **出處**：[s、n、g 變動效果比較](../wiki/synthesis/s%E3%80%81n%E3%80%81g%20%E8%AE%8A%E5%8B%95%E6%95%88%E6%9E%9C%E6%AF%94%E8%BC%83.md)、[Solow 新古典成長模型](../wiki/models/Solow%20%E6%96%B0%E5%8F%A4%E5%85%B8%E6%88%90%E9%95%B7%E6%A8%A1%E5%9E%8B.md)（來源第 26 張）

## P19 技術進步：唯一的長期引擎
- **版型**：圖表＋說明
- **重點**：長期人均所得成長率＝技術進步率 g
- **公式**：g = ΔA/A
- **內容要點**：f(k) 與 sf(k) 每年上移，穩態 k*₀ → k*₁ → k*₂；限制：g 是外生的，模型沒解釋技術從哪來
- **視覺**：`solow-tech`：三組 f(k, A) 與 sf(k)
- **出處**：[全要素生產力 (TFP)](../wiki/concepts/%E5%85%A8%E8%A6%81%E7%B4%A0%E7%94%9F%E7%94%A2%E5%8A%9B%20%28TFP%29.md)（來源第 27 張）

## P20 黃金法則：存太多也不好
- **版型**：圖表＋說明
- **重點**：穩態消費最大的條件是 MPK = n + δ
- **公式**：c = (1−s)y；MPK = n + δ
- **內容要點**：存得多 → 現在能花的比例↓；存得多 → 資本與所得↑；兩股力量拉扯 → 存在最佳儲蓄率 s_g
- **視覺**：`solow-golden`：切線斜率 n+δ、最大垂直距離 c_g*、點 Q
- **📝**：MPK 是多一單位資本能多生產多少；n+δ 是多維護一單位機器要付出多少成本
- **出處**：[黃金法則](../wiki/concepts/%E9%BB%83%E9%87%91%E6%B3%95%E5%89%87.md)（來源第 29–33 張）

## P21 總整理：三個參數的效果
- **版型**：表格
- **重點**：只有 g 能讓人均所得長期成長
- **內容要點**：s↑（曲線上移；y*↑；人均成長 0；總成長 n）、n↑（直線變陡；y*↓；0；↑）、δ↑（直線變陡；y*↓；0；n）、g（曲線持續上移；持續↑；g；n+g）

- **出處**：[s、n、g 變動效果比較](../wiki/synthesis/s%E3%80%81n%E3%80%81g%20%E8%AE%8A%E5%8B%95%E6%95%88%E6%9E%9C%E6%AF%94%E8%BC%83.md)
