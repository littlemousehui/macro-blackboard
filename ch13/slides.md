## P05 帳一定要平：經常帳＋資本帳＝0
- **版型**：公式＋比喻
- **重點**：花得比賺得多，就得賣資產或借錢
- **公式**：經常帳 ＋ 資本帳 ＝ 0
- **比喻**：💳 個人花超過收入 → 賣東西或借錢（簡報原文的個人例子）；刷卡比喻為補充
- **內容要點**：國家經常帳赤字 → 賣資產或向外借 → 資本帳盈餘；美國長期經常帳赤字由民間資本流入支應
- **📝**：經常帳的赤字會伴隨對等的資本流入
- **出處**：[國際收支](../wiki/indicators/%E5%9C%8B%E9%9A%9B%E6%94%B6%E6%94%AF.md)（來源第 6–7 張）

## P06 匯率是什麼？
- **版型**：公式＋例子
- **重點**：一種貨幣以另一種貨幣表示的價格
- **例子**：1999 年 8 月 1 愛爾蘭鎊 = 1.38 美元 → e = 1.38；三明治 2.39 鎊 → 1.38 × 2.39 = 3.30 美元
- **內容要點**：兩種制度：固定匯率、浮動匯率
- **📝**：一種貨幣相對另一種的價格；簡報印 1.39，已更正為 1.38
- **出處**：[名目匯率與實質匯率](../wiki/concepts/%E5%90%8D%E7%9B%AE%E5%8C%AF%E7%8E%87%E8%88%87%E5%AF%A6%E8%B3%AA%E5%8C%AF%E7%8E%87.md)（來源第 8 張）

## P07 固定匯率：央行守價格
- **版型**：雙欄
- **重點**：央行用固定價格買賣，靠外匯存底干預
- **內容要點**：沒人會用高於固定價買美元、也沒人會用低於固定價賣；干預＝央行買賣外匯；干預力道取決於國際收支缺口；例：美國對日逆差 → 日圓需求 > 供給 → 日本央行買進多餘美元、付出日圓
- **比喻**：守門員守住球門價格（補充比喻）
- **📝**：本國貨幣和另一種貨幣維持一個固定的兌換比率；為了不讓日元升值，買進多餘美金；央行必須持有外幣庫存（外匯存底）
- **出處**：[匯率制度](../wiki/policies/%E5%8C%AF%E7%8E%87%E5%88%B6%E5%BA%A6.md)、[外匯干預與外匯存底](../wiki/concepts/%E5%A4%96%E5%8C%AF%E5%B9%B2%E9%A0%90%E8%88%87%E5%A4%96%E5%8C%AF%E5%AD%98%E5%BA%95.md)（來源第 9–10 張）

## P08 存底用完會怎樣？
- **版型**：流程
- **重點**：持續逆差 → 存底耗盡 → 存底歸零前貶值
- **內容要點**：有足夠存底可持續干預；持續逆差：① 對外幣需求遠大於供給 ② 存底耗盡 ③ 無法再干預 ④ 之前央行就會讓貨幣貶值
- **視覺**：存底水位下降圖示（HTML 長條）
- **📝**：對外幣需求遠大於供給；最終耗盡外匯存底；在存底歸 0 前，央行會主動貶值
- **出處**：[外匯干預與外匯存底](../wiki/concepts/%E5%A4%96%E5%8C%AF%E5%B9%B2%E9%A0%90%E8%88%87%E5%A4%96%E5%8C%AF%E5%AD%98%E5%BA%95.md)（來源第 11 張）

## P09 浮動匯率：交給市場
- **版型**：步驟
- **重點**：日圓需求↑ → 日圓升值 → 日本貨變貴 → 需求↓
- **內容要點**：央行讓匯率調整使外幣供需相等；例：0.86 美分／日圓 → 日本對美出口↑ → 要付更多日圓 → 日本央行不干預 → 升到 0.90 美分 → 日本貨以美元計變貴 → 美國人需求下降
- **📝**：央行允許匯率波動，匯率高低完全由外匯市場供給和需求決定；日元需求增加；價格↑，需求↓
- **出處**：[匯率制度](../wiki/policies/%E5%8C%AF%E7%8E%87%E5%88%B6%E5%BA%A6.md)（來源第 12 張）

## P10 長期：購買力平價
- **版型**：圖表＋說明
- **重點**：同一筆錢在國內外應該買到同樣的東西；長期傾向成立
- **內容要點**：長期匯率由相對購買力決定；PPP：一單位本國貨幣在國內外能買到相同一籃商品；英荷大麥（約 1370–1980）：傾向相等，但有長期偏離；現代估計偏離約 4 年減半；PPP 只是決定匯率的因素之一
- **視覺**：`barley`：示意波動折線圍繞 0（標「示意，仿 Figure 13-2」）
- **📝**：匯率長期要看購買力；一單位本國貨幣在國內外能買到相同數量商品；實質大麥匯率傾向相等；長期的偏離
- **出處**：[購買力平價 (PPP)](../wiki/concepts/%E8%B3%BC%E8%B2%B7%E5%8A%9B%E5%B9%B3%E5%83%B9%20%28PPP%29.md)（來源第 13、15–16 張）

## P11 實質匯率 R = ePf / P
- **版型**：公式＋拆解
- **重點**：換一單位外國貨，要用幾單位本國貨
- **公式**：$R = \frac{eP_f}{P}$
- **內容要點**：e 名目匯率、Pf 外國物價、P 本國物價；R = 1 → PPP；R > 1 → 外國貨較貴；R < 1 → 外國貨較便宜；⚠️ 簡報第 22 張把 R 誤稱實質利率
- **📝**：實質匯率、名目匯率、外國物價、本國物價（公式標註）；用本國商品換取一單位外國商品所需數量
- **出處**：[名目匯率與實質匯率](../wiki/concepts/%E5%90%8D%E7%9B%AE%E5%8C%AF%E7%8E%87%E8%88%87%E5%AF%A6%E8%B3%AA%E5%8C%AF%E7%8E%87.md)（來源第 13–14、17 張）

## P12 貶值是好事還是壞事？
- **版型**：雙卡片
- **重點**：本幣貶值（R↑）出口有利、經常帳改善；升值（R↓）相反
- **內容要點**：R 2→3：1 單位外國貨換 3 單位本國貨 → 本國貨相對便宜 → 對本國貨需求↑ → 出口有利、經常帳改善；R 2→1：本國貨相對變貴 → 進口有利、出口不利 → 經常帳惡化
- **出處**：[名目匯率與實質匯率](../wiki/concepts/%E5%90%8D%E7%9B%AE%E5%8C%AF%E7%8E%87%E8%88%87%E5%AF%A6%E8%B3%AA%E5%8C%AF%E7%8E%87.md)（來源第 17–18 張）

## P13 工具一：IS 曲線（商品市場）
- **版型**：圖表＋推論鏈
- **重點**：利率↓ → 投資↑ → 產出↑，所以 IS 向右下
- **內容要點**：IS＝讓商品市場均衡的所有 (Y, i)；Y = Y^d = C + I + G + (X − Q)；I = I(i)；利率↓ → 資金成本↓ → 資本↑ → 投資↑；假設物價固定、供給無虞；🔣 進口用 Q
- **視覺**：`is-curve`
- **📝**：IS：國際商品市場；物價固定、供給無虞
- **出處**：[IS-LM 模型](../wiki/models/IS-LM%20%E6%A8%A1%E5%9E%8B.md)（來源第 19、28、39–41 張）

## P14 工具二：LM 曲線（貨幣市場）
- **版型**：圖表＋推論鏈
- **重點**：產出↑ → 貨幣需求↑ → 利率↑，所以 LM 向右上
- **內容要點**：LM＝讓貨幣市場均衡的所有 (Y, i)；M^s = M̄（央行控制）；M^d = M^d(i, Y, P)；IS 與 LM 交點 E 決定 Y* 與 i*
- **視覺**：`islm`：IS、LM 與交點 E
- **📝**：LM：貨幣市場
- **出處**：[IS-LM 模型](../wiki/models/IS-LM%20%E6%A8%A1%E5%9E%8B.md)（來源第 28、42–43 張）

## P15 打開國門：淨出口加進 IS
- **版型**：公式＋表格
- **重點**：外國所得↑、本幣實質貶值 → IS 右移
- **公式**：$DS = C + I + G$；$Y = DS(Y, i) + NX(Y, Y_f, R)$；$NX = X(Y_f, R) - Q(Y, R)$
- **內容要點**：表：Y_f↑ → 貿易餘額改善、AD↑；R↑ → 改善、AD↑；Y↑ → 進口↑、惡化；外國需求增加 → 任何利率下 AD 都增加 → IS 右移 → 利率、產出、就業上升
- **視覺**：`is-shift`（仿 Figure 13-3：IS → IS′，E → E′）
- **📝**：國內居民的支出；出口取決於外國所得、實質匯率；貿易餘額改善；Q↑，NX↓；NX 增加，在任何利率水準 AD 都增加
- **出處**：[淨出口](../wiki/concepts/%E6%B7%A8%E5%87%BA%E5%8F%A3.md)、[IS-LM 模型](../wiki/models/IS-LM%20%E6%A8%A1%E5%9E%8B.md)（來源第 19–23 張）

## P16 錢會漏到國外：邊際進口傾向
- **版型**：雙欄
- **重點**：多賺的錢一部分買進口品，所以開放經濟的 IS 比較陡
- **內容要點**：邊際進口傾向 m＝國內所得多 1 元，進口增加多少；利率下降 → 投資↑ → 產出↑，但所得一部分漏到進口 → 只需較小的產出增加就能恢復均衡 → IS 較陡；與第14章 MPC 對照：MPC 回流本國、m 漏出國外（對照為補充）
- **比喻**：水桶漏水：國內需求有一部分從進口這個洞流走（補充比喻）
- **📝**：GDP 每增加一元會導致進口支出增加的金額；i↓ → 投資增加 → Y↑
- **出處**：[邊際進口傾向](../wiki/concepts/%E9%82%8A%E9%9A%9B%E9%80%B2%E5%8F%A3%E5%82%BE%E5%90%91.md)（來源第 5、21 張）

## P17 資金哪裡報酬高就往哪跑
- **版型**：雙欄＋公式
- **重點**：完全資本移動下，利率被釘在世界利率 i_f
- **公式**：$BP = NX(Y, Y_f, R) + CF(i - i_f)$
- **內容要點**：完全資本移動：任何國家、快速、低成本、不限量；i > i_f → 資本流入；i < i_f → 資本流出；最小利差引發無限資本流動 → BP = 0 只在 i = i_f → 圖上是水平線
- **視覺**：`bp-line`：BP = 0 水平線，上方「資本流入」、下方「資本流出」
- **📝**：無障礙交易；錢會往高報酬或借貸成本低走；國內利率高於世界利率時會購買國內；利差
- **出處**：[資本移動性](../wiki/concepts/%E8%B3%87%E6%9C%AC%E7%A7%BB%E5%8B%95%E6%80%A7.md)、[國際收支](../wiki/indicators/%E5%9C%8B%E9%9A%9B%E6%94%B6%E6%94%AF.md)（來源第 24–26、31 張）

## P18 Mundell-Fleming：開放經濟版 IS-LM
- **版型**：圖表＋說明
- **重點**：IS、LM 加上 BP = 0 水平線，利率只能等於 i_f
- **內容要點**：由 Mundell 與 Fleming 提出；把外匯與完全資本移動加進 IS-LM；假設國內物價固定；最小利差引發無限資本流入 → 固定匯率下央行無法執行獨立貨幣政策（為什麼？下一頁）
- **視覺**：`mf-base`：IS、LM、BP = 0 交於 E
- **📝**：資本高度自由流動；固定匯率 → 央行不能升值或貶值；假設國內價格固定
- **出處**：[Mundell-Fleming 模型](../wiki/models/Mundell-Fleming%20%E6%A8%A1%E5%9E%8B.md)、[孟岱爾 (Robert Mundell)](../wiki/people/%E5%AD%9F%E5%B2%B1%E7%88%BE%20%28Robert%20Mundell%29.md)、[弗萊明 (Marcus Fleming)](../wiki/people/%E5%BC%97%E8%90%8A%E6%98%8E%20%28Marcus%20Fleming%29.md)（來源第 26、30 張）

## P19 固定匯率＋貨幣擴張：沒用
- **版型**：圖表＋流程
- **重點**：LM 右移 → 資本流出 → 央行收回本幣 → LM 回到原位
- **內容要點**：① 貨幣擴張 → LM 右移到 E′，i < i_f ② 國際收支逆差、貶值壓力 ③ 央行賣外匯、收回本幣 ④ 貨幣供給下降，LM 回原位 → 貨幣政策無效；反向（緊縮）也一樣：i↑ → 資金湧入 → 央行釋出本幣 → i 回落
- **視覺**：`mf-fix-money`：LM、LM′、IS、BP，箭頭 LM′ → LM
- **📝**：賣外匯買本國；緊縮貨幣 i↑；大量資金湧入；因為外國人要賣外幣買本幣；釋放本幣 → i↓
- **出處**：[Mundell-Fleming 模型](../wiki/models/Mundell-Fleming%20%E6%A8%A1%E5%9E%8B.md)（來源第 27–28 張）

- **內容要點**：① 財政擴張 → IS 右移，i↑、Y↑ ② 資本流入、升值壓力 ③ 央行必須擴張貨幣 → LM 右移 ④ 利率回到 i_f，產出再增加

## P21 浮動匯率＋財政擴張：沒用
- **版型**：圖表＋流程
- **重點**：IS 右移 → 資本流入 → 本幣升值 → NX↓ → IS 被推回
