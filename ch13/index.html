國家靠兩條管道連在一起

各國經濟愈來愈相互依存：美國衰退會拖累別國，美國擴張會帶動別國。

📦 管道一：貿易

  • 出口 → 外國人買本國貨，增加本國需求
  • 進口 → 本國人的錢花到國外，是所得循環的漏出

💵 管道二：金融

  • 基金經理人在全世界找最高報酬
  • 資金搬來搬去 → 影響所得、匯率，以及貨幣政策能不能影響利率

國家的記帳本：國際收支

國際收支：本國居民和世界其他國家交易的紀錄。

經常帳

商品和服務的貿易，加上移轉支付（例如政府援助）。

資本帳

資產的買賣：股票、債券、土地。

匯率是什麼？

匯率＝一種貨幣用另一種貨幣表示的價格

🥪 愛爾蘭的三明治

1999 年 8 月，1 愛爾蘭鎊可以換 1.38 美元 → 名目匯率 e = 1.38

三明治賣 2.39 鎊，換成美元是：

1.38 × 2.39 = $3.30

兩種匯率制度

  1. 固定匯率：央行把價格守住
  2. 浮動匯率：交給市場決定
一種貨幣相對另一種的價格；簡報印 1.39，已更正為 1.38。

固定匯率：央行守價格

央行用固定價格買賣本國貨幣：

  • 沒人會用比固定價更貴的價格買美元
  • 沒人會用比固定價更便宜的價格賣美元

央行在外匯市場買賣外幣，叫做干預；要干預多少，取決於國際收支的缺口。

🧤 就像守門員，球（價格）往哪偏就往哪撲（比喻為補充）

🇯🇵 日本的例子

美國對日本有逆差 → 想換日圓的人比想賣日圓的人多 → 日圓有升值壓力

→ 日本央行買進多餘的美元、付出日圓，把匯率壓回固定價。

→ 所以央行手上必須有一筆外幣庫存：外匯存底。

本國貨幣和另一種貨幣維持一個固定的兌換比率；為了不讓日元升值，買進多餘美金；央行必須持有外幣庫存（外匯存底）。

長期：購買力平價（PPP）

英國／荷蘭大麥價格比（對數），示意圖，仿 Figure 13-2

長期來看，匯率由兩國貨幣的購買力決定。

購買力平價：同一單位本國貨幣，在國內和國外能買到一樣多的東西。

  • 600 年的大麥價格：傾向相等（圍著 0 上下跑）
  • 但有很長的偏離期
  • 現代估計：偏離約 4 年縮小一半

PPP 長期成立，但只是決定匯率的因素之一。

匯率長期要看購買力；一單位本國貨幣在國內外能買到相同數量商品；實質大麥匯率傾向相等；長期的偏離。

貶值是好事還是壞事？

經常帳改善

📈 本幣升值：R 從 2 → 1

1 單位外國貨只能換 1 單位本國貨

→ 本國貨相對變貴

→ 進口有利、出口不利

經常帳惡化

所以貶值對出口商是好消息，對買進口品的消費者是壞消息。

完全資本移動：投資人可以在任何國家、快速、低成本、不限量地買賣資產。

BP = NX + CF(i − if)
  • i > if（本國利率比世界高）→ 資本流入
  • i < if → 資本流出

差一點點就會引發大量資金流動 → 國際收支只在 i = if 平衡 → 圖上是一條水平線。

無障礙交易；錢會往高報酬或借貸成本低走；國內利率高於世界利率時會購買國內；利差。

Mundell-Fleming：開放經濟版 IS-LM

由 Mundell 和 Fleming 提出：把匯率和完全資本移動加進 IS-LM。

  • 藍線 IS：商品市場
  • 綠線 LM：貨幣市場
  • 白線 BP = 0：國際收支平衡，利率被釘在 if

假設國內物價固定。三條線交在 E。

接下來四頁：
固定 / 浮動匯率 × 貨幣 / 財政政策

資本高度自由流動；固定匯率 → 央行不能升值或貶值；假設國內價格固定。

固定匯率＋貨幣擴張：沒用

  1. 央行多印錢 → LM 右移到 LM′，利率跌到 if 以下（E′）
  2. 資金往外跑 → 國際收支逆差、貶值壓力
  3. 為了守匯率，央行賣外匯、收回本幣
  4. 錢又變少 → LM 退回原位

結果：貨幣政策無效

反過來緊縮也一樣：利率↑ → 資金湧入 → 央行被迫釋出本幣 → 利率又降回來。

賣外匯買本國；緊縮貨幣 i↑ → 大量資金湧入（外國人要賣外幣買本幣）→ 釋放本幣 → i↓。

固定匯率＋財政擴張：很有效

  1. 政府多花錢 → IS 右移，利率、產出都上升（E′）
  2. 利率高於 if → 資金湧入、升值壓力
  3. 為了守匯率，央行必須釋出本幣 → LM 也右移
  4. 利率回到 if，產出再增加（E″）

結果：財政政策效果最大

財政政策；釋出本幣 → i↓。

浮動匯率＋財政擴張：沒用

浮動匯率：央行不干預，國際收支自動平衡；i > if → 升值 → IS 左移。

  1. 政府多花錢（或出口增加）→ IS 右移到 E′
  2. 利率高於 if → 外資湧入
  3. 本幣升值 → 本國貨變貴 → 淨出口↓
  4. IS 被推回去，經濟回到 E

結果：財政政策無效

浮動匯率央行不干預外匯市場；BP = 0；在浮動匯率無效：政府撒錢 → i > i_f → 外資湧入 → 本幣升值。

浮動匯率＋貨幣擴張：很有效

  1. 央行多印錢 → 利率↓ → LM 右移到 E′
  2. 利率低於 if → 資本流出、本幣貶值
  3. 進口變貴、本國貨變便宜 → 淨出口↑
  4. IS 右移到 E″，利率回到 if

結果：產出增加＋本幣貶值

⚠️ 原簡報第 35 張寫成「capital inflows」，依邏輯應為資本流出。

在 E′ 點 i < i_f → 投資人賣本幣買外幣 → 本幣貶值，本國貨變便宜 → 國內需求增加，NX↑ → IS 向右。

Mundell（1963），假設完全資本移動

固定匯率：財政有效、貨幣沒用——守匯率就交出了貨幣的方向盤。
浮動匯率：貨幣有效、財政沒用——匯率自己動，把財政刺激吃掉。
補充：不可能三角——固定匯率、資本自由移動、獨立貨幣政策，三個最多只能選兩個。

回到新興市場＋重點回顧

用模型讀 2022 年的風險

推論（非簡報原文）：美國升息 → 世界利率 if↑ → 新興市場資本流出 → 浮動匯率國貨幣貶值、固定匯率國耗用存底；中國放緩 → Yf↓ → 新興市場出口減少。

五個重點

  1. 經常帳＋資本帳＝0
  2. 固定匯率要靠外匯存底干預
  3. 長期看 PPP；實質匯率 R = ePf/P
  4. 開放經濟 IS 加入淨出口，而且比較陡
  5. Mundell-Fleming 政策四格表

常見誤解

  • ❌ 貶值一定是壞事
  • ❌ 固定匯率下央行還能自由調整貨幣
  • ❌ 浮動匯率下財政擴張是靠利率排擠投資（其實是升值排擠淨出口）
  • ❌ 浮動匯率貨幣擴張會帶來「資本流入」
