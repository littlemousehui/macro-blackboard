# 大綱：第13章 國際連結

## 故事線
**貫穿問題**：「美國一升息，為什麼新興市場跟著緊張？**在全球化的世界裡，一國的政策還有效嗎？**」
先看國家怎麼透過貿易和資金連在一起（國際收支、匯率），再補上短期分析工具 IS-LM，最後用 Mundell-Fleming 模型回答：固定匯率和浮動匯率下，貨幣政策和財政政策誰有效。

