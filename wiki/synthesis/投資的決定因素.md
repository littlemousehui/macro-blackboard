# 投資的決定因素

> 考前總整理：從「利率」到「投資」的整條路，以及每個因素怎麼影響投資。

## 一條推論鏈
```mermaid
flowchart LR
  A[名目利率 i] --> B[實質利率<br/>r = i − π^e] --> C[租賃成本<br/>rc = r + δ] --> D[最適資本存量<br/>K* = g(rc, Y)] --> E[缺口<br/>K* − K₋₁] --> F[投資<br/>I = λ(K* − K₋₁)]
  Y[產出 Y] --> D
```
（[第15章 投資支出](../sources/%E7%AC%AC15%E7%AB%A0%20%E6%8A%95%E8%B3%87%E6%94%AF%E5%87%BA.md) 第 7–14 張）

## 各因素的影響
| 因素變動 | 傳導 | 投資 |
|---|---|---|
| 名目利率 $i$↑ | $rc$↑ → $K^*$↓ | ↓ |
| 預期通膨 $\pi^e$↑ | $r$↓ → $rc$↓ → $K^*$↑ | ↑ |
| 折舊率 $\delta$↑ | $rc$↑ → $K^*$↓ | ↓ |
| 產出 $Y$↑（或預期需求↑） | $K^*$↑ | ↑ |
| 資本邊際產出↑（新技術） | $K^*$↑ | ↑ |
| 調整速度 $\lambda$↑ | 缺口補得更快 | 短期↑ |
| 房貸利率↑ | — | 住宅投資↓ |
（前三列由 $rc$ 公式推得；房貸利率見 Figure 15-7）

## 一句話記憶
**利率決定成本，成本決定想要多少資本，缺口決定投資多快。**

## 常考陷阱
1. 投資是**流量**、資本是**存量**，不要混用。
2. 租賃成本用的是**實質**利率 $i - \pi^e$，不是名目利率。
3. $K^*$ 不變時，投資會隨缺口縮小而**遞減**到只剩補折舊。
4. 三個部門中，「最大」是企業固定投資，「波動最大」是存貨投資。
