# 彈性加速模型（Flexible Accelerator Model）

> 一句話：企業每一期只補上「實際資本」和「想要的資本」之間缺口的**一部分**；缺口愈大，投資愈多。

（[第15章 投資支出](../sources/%E7%AC%AC15%E7%AB%A0%20%E6%8A%95%E8%B3%87%E6%94%AF%E5%87%BA.md) 第 12–14 張；📝「彈性加速模型解釋企業調整資本存量的速度」）

## 基本想法
現有資本存量和[期望資本存量](%E6%9C%80%E9%81%A9%E8%B3%87%E6%9C%AC%E5%AD%98%E9%87%8F.md)的差距**愈大**，企業的投資速度**愈快**（📝「越大越快」）。

## 方程式
| 符號 | 意義 |
|---|---|
| $K_{-1}$ | 上一期期末的資本存量 |
| $K^*$ | 期望資本存量（📝） |
| $K^* - K_{-1}$ | 缺口 |
| $\lambda$ | 每期補上缺口的比例（調整速度，📝「速度」） |
| $K_0$ | 本期期末的實際資本存量（📝「期末實際資本存量」） |

$$ K_0 = K_{-1} + \lambda(K^* - K_{-1}) \qquad (2) $$

要從 $K_{-1}$ 增加到 $K_0$，需要的**淨投資**是（第 13 張）：
$$ I \equiv K_0 - K_{-1} = \lambda(K^* - K_{-1}) \qquad (3) $$
📝「$K_0 = K_{-1} + I = K_{-1} + \lambda(K^* - K_{-1})$」

## 圖形（Figure 15-5，第 13–14 張）
- 上圖：資本存量一期一期往 $K^*$ 靠近（藍色長條逐漸變高）
- 下圖：每期投資一期比一期小（第一期最大 $K_0 - K_{-1}$，第二期 $K_1 - K_0$ …）
📝「λ，缺口越來越小」

```
 K* ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄
    │    ▇ ▇ ▇ ▇ ▇ ▇
    │  ▇ █ █ █ █ █ █    資本存量逐期逼近 K*
 K₋₁│█ █ █ █ █ █ █ █
    └──────────────── 時間
  I │  █
    │  █ █               投資逐期遞減
    │  █ █ ▅ ▃ ▂ ▁ ▁
    └──────────────── 時間
```

## 含意（第 14 張）
- 投資是 $K^*$ 與 $K_{-1}$ 的函數。
- **任何讓 $K^*$ 上升的因素，都會提高投資**（例如租賃成本下降、產出增加）。
- 投資具有**動態**特性：一次 $K^*$ 的變動，會帶來好幾期逐漸遞減的投資。

## 例子（補充）
設 $\lambda = 0.5$，$K^* = 100$，$K_{-1} = 60$：第一期投資 20（資本到 80），第二期 10（到 90），第三期 5（到 95）……
