# 凱因斯消費函數（Keynesian Consumption Function）

> 一句話：早期凱因斯理論認為，**這一期的消費取決於這一期的可支配所得**。

## 適用範圍與假設（[第14章 消費與儲蓄](../sources/%E7%AC%AC14%E7%AB%A0%20%E6%B6%88%E8%B2%BB%E8%88%87%E5%84%B2%E8%93%84.md) 第 7 張）
- 消費是**當期可支配所得**的函數。
- **不區分**暫時所得與恆常所得（見[恆常所得與暫時所得](../concepts/%E6%81%86%E5%B8%B8%E6%89%80%E5%BE%97%E8%88%87%E6%9A%AB%E6%99%82%E6%89%80%E5%BE%97.md)）。
- 只有**單一**的邊際消費傾向。

## 變數
| 符號 | 意義 |
|---|---|
| $C_t$ | 第 t 期消費 |
| $\bar C$ | 自發性消費（與所得無關的部分） |
| $c$（MPC） | [邊際消費傾向 (MPC)](../concepts/%E9%82%8A%E9%9A%9B%E6%B6%88%E8%B2%BB%E5%82%BE%E5%90%91%20%28MPC%29.md)，介於 0 與 1 之間 |
| $YD_t$ | 第 t 期可支配所得（disposable income） |

## 方程式
$$ C_t = \bar C + c\,YD_t \qquad (1), \quad 0 \le c \le 1 $$

🔣 這裡的小寫 $c$ 是 MPC，和第3章的人均消費 $c$ 不同。

## 圖形
Figure 14-3（第 7 張）：美國人均消費對人均可支配所得的散布點，幾乎落在一條直線上——長期來看，消費與所得關係很穩定。

```
 C │                    ／
   │                 ／   斜率 = c（MPC）
   │              ／
   │           ／
   │        ／
 C̄ │─────／
   │
   └──────────────────── YD
```

## 直覺
多賺一塊錢，就花掉 $c$ 元、存下 $1-c$ 元。

## 限制與批評
- 不管所得是一次性的還是永久的，都用同一個 MPC → 無法解釋「消費不回應所得短暫暴衝」（Figure 14-1，見[民間消費](../indicators/%E6%B0%91%E9%96%93%E6%B6%88%E8%B2%BB.md)）。
- 現代消費理論加入**跨期**的考量：[生命週期理論](%E7%94%9F%E5%91%BD%E9%80%B1%E6%9C%9F%E7%90%86%E8%AB%96.md)、[恆常所得理論](%E6%81%86%E5%B8%B8%E6%89%80%E5%BE%97%E7%90%86%E8%AB%96.md)、[隨機漫步消費模型 (Hall)](%E9%9A%A8%E6%A9%9F%E6%BC%AB%E6%AD%A5%E6%B6%88%E8%B2%BB%E6%A8%A1%E5%9E%8B%20%28Hall%29.md)。（第 7 張）
- 消費理論之爭＝MPC 大小之爭：凱因斯模型 MPC 高，現代理論 MPC 低。（第 4 張）比較見[消費理論比較](../synthesis/%E6%B6%88%E8%B2%BB%E7%90%86%E8%AB%96%E6%AF%94%E8%BC%83.md)。

## 常見考點與誤解
- 凱因斯消費函數的 MPC 是「當期所得」的 MPC；現代理論區分恆常與暫時所得的 MPC。
- $\bar C$ 讓「平均消費傾向 C/YD」會隨所得上升而下降（補充推論）。
