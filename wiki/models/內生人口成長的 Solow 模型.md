# 內生人口成長的 Solow 模型

> 一句話：當**人口成長率隨所得變動** $n(y)$，Solow 圖會出現三個均衡，其中最低的那個就是**[貧窮陷阱](../concepts/%E8%B2%A7%E7%AA%AE%E9%99%B7%E9%98%B1.md)**。

## 背景（第 21 張）
經濟學最古老的想法之一：人口成長不利於達到高所得。[Solow 新古典成長模型](Solow%20%E6%96%B0%E5%8F%A4%E5%85%B8%E6%88%90%E9%95%B7%E6%A8%A1%E5%9E%8B.md)預測：n 愈高，穩態所得愈低，因為每個勞工分到的資本較少（📝「每人分到的 k 減少」）。

## 假設：人口成長率取決於所得 $n(y)$
| 所得水準 | 出生率 | 死亡率 | 人口成長 |
|---|---|---|---|
| 非常貧窮 | 高 | 高 | 中等 |
| 所得上升 | 高 | **下降** | **上升** |
| 非常富裕 | **下降** | 低 | 趨近零人口成長（ZPG） |

## 圖形（文字＋示意）
Figure 4-3：必要投資線變成 $[n(y)+\delta]k$——低所得時緩升、中所得時陡升、高所得時又趨平。它和 $sf(k)$ 交於 A、B、C 三點。（第 22–23 張）

```
 y │                         ____---- f(k)
   │              ____---‾‾‾
   │        __--‾‾          C●───── [n(y)+δ]k
   │      /         ____--‾‾ ←← sf(k)
   │     /    →→B●‾‾
   │    /   ／←←
   │   / A●              A：貧窮陷阱（穩定）
   │  /／                B：不穩定（往兩邊跑）
   │ ／                  C：高所得（穩定）
   └──┼─────┼───────────┼──── k
      k*A   k*B         k*C
```

| 均衡 | 性質 | 說明 |
|---|---|---|
| A | **穩定** | 貧窮陷阱：人口成長高、所得低 |
| B | **不穩定** | 經濟會離開 B，往 A 或 C 移動 |
| C | **穩定** | 人口成長低、所得高 |

## 如何脫離低水準均衡（第 24 張）
1. **[大推力](../concepts/%E5%A4%A7%E6%8E%A8%E5%8A%9B.md)**（big push）：一口氣把所得推過 B 點，經濟就會自己走向 C。
2. **移動曲線**，讓它們不再於 A、B 相交：
   - 提高**生產力**或**儲蓄率** → 儲蓄曲線上移
   - **人口政策** → 必要投資線下移（📝「降低 n」）

詳見[成長政策](../policies/%E6%88%90%E9%95%B7%E6%94%BF%E7%AD%96.md)。

## 與其他模型的關係
- 是 [Solow 新古典成長模型](Solow%20%E6%96%B0%E5%8F%A4%E5%85%B8%E6%88%90%E9%95%B7%E6%A8%A1%E5%9E%8B.md) 的擴充：把外生的 n 改為 $n(y)$。
- 與 [兩部門成長模型](%E5%85%A9%E9%83%A8%E9%96%80%E6%88%90%E9%95%B7%E6%A8%A1%E5%9E%8B.md) 同樣產生「陷阱」，但陷阱的來源不同。

## 常見考點與誤解
- 判斷穩定性：看交點兩側的箭頭方向。$sf(k) > [n(y)+\delta]k$ 時 k 增加（往右），反之往左。
- 三個交點中只有 A、C 是穩定的；B 是「分水嶺」。
