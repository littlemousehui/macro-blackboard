# Mundell-Fleming 模型

> 一句話：把**匯率**與**完全資本移動**加進 [IS-LM 模型](IS-LM%20%E6%A8%A1%E5%9E%8B.md)；結論是——**固定匯率下貨幣政策無效、財政政策最有效；浮動匯率下剛好相反**。

由 [孟岱爾 (Robert Mundell)](../people/%E5%AD%9F%E5%B2%B1%E7%88%BE%20%28Robert%20Mundell%29.md) 與 [弗萊明 (Marcus Fleming)](../people/%E5%BC%97%E8%90%8A%E6%98%8E%20%28Marcus%20Fleming%29.md) 提出。（[第13章 國際連結](../sources/%E7%AC%AC13%E7%AB%A0%20%E5%9C%8B%E9%9A%9B%E9%80%A3%E7%B5%90.md) 第 26 張）

## 適用範圍與假設
- 短期，國內物價固定（📝「假設國內價格固定」）。（第 30 張）
- **完全[資本移動性](../concepts/%E8%B3%87%E6%9C%AC%E7%A7%BB%E5%8B%95%E6%80%A7.md)**：最小的利差就會引發無限的資本流動。（第 26 張）
- 小型開放經濟：面對給定的進口價格、出口需求與世界利率 $i_f$。（第 25 張）

## 方程式
| 式 | 內容 |
|---|---|
| (8) IS | $Y = DS(Y, i) + NX(Y, Y_f, R)$ |
| (9) 國際收支 | $BP = NX(Y, Y_f, R) + CF(i - i_f)$ |
| (10) 完全資本移動 | $BP = 0$ 當 $i = i_f$ |

- $CF$：資本帳盈餘，取決於利差（📝「利差」）；$i > i_f$ → 資本流入。
- 圖上 $BP = 0$ 是一條在 $i = i_f$ 的**水平線**（📝「因為當 $i > i_f$ 資本流入，$i < i_f$ 資本流出」）。（第 31 張）

## 一、固定匯率（第 26–29 張）
📝「固定匯率 → 央行不能升值或貶值」

### 貨幣政策：無效
```mermaid
flowchart LR
  A[緊縮貨幣<br/>i↑] --> B[全球資金湧入] --> C[BP 大幅盈餘<br/>本幣升值壓力] --> D[央行買外幣<br/>釋出本幣] --> E[貨幣存量↑<br/>i↓ 回到原水準]
```
（第 27 張；📝「緊縮貨幣 i↑」「大量資金湧入」「因為外國人要賣外幣買本幣」「釋放本幣 → i↓」）

貨幣擴張（Figure，第 28 張）：LM 右移到 E′ → $i < i_f$、國際收支逆差、貶值壓力 → 央行**賣外匯、收回本幣**（📝「賣外匯買本國」）→ 貨幣供給下降 → LM 回到原位。
→ **央行無法執行獨立的貨幣政策**。

### 財政政策：有效
財政擴張 → IS 右移 → $i$↑、$Y$↑ → 資本流入、升值壓力 → 央行**必須**擴張貨幣（📝「釋出本幣 → i↓」）→ LM 右移 → 利率回到原水準，產出**再增加**。（第 29 張）

## 二、浮動匯率（第 30–36 張）
- 央行不干預外匯市場；匯率調整使外匯供需相等 → **$BP = 0$**（📝「浮動匯率央行不干預外匯市場」）
- 央行可自由決定貨幣供給，**貨幣供給與國際收支沒有自動連動**（📝）

匯率與 IS（Figure 13-6，第 31–32 張）：
- $i > i_f$ → 本幣**升值** → 本國商品變貴 → IS **左移**
- $i < i_f$ → 本幣**貶值** → 本國商品變便宜 → IS **右移**

### 實質衝擊（出口增加）與財政擴張：無效
出口↑或 $G$↑ → IS 右移到 E′（$Y$↑、$i$↑）→ $i > i_f$、資本流入 → 本幣升值 → IS 被推回 E。（第 33–34 張）
→ **浮動匯率下，增加政府支出不影響均衡產出**（📝「在浮動匯率無效」「政府撒錢 → i > i_f → 外資湧入 → 本幣升值」）

### 貨幣擴張：有效
（第 35–36 張）
1. 名目貨幣供給↑ → 實質貨幣 $M/P$↑（P 固定）
2. 實質貨幣超額供給 → 利率下降 → LM 右移
3. 在 E′：商品市場均衡，但 $i < i_f$ → **資本流出**、本幣貶值
   - ⚠️ 簡報第 35 張寫成「capital inflows」，依邏輯與 📝 應為流出
4. 進口變貴、本國商品更有競爭力 → 對本國商品需求增加 → IS 右移到 E″（$i = i_f$）

結果：**貨幣擴張使產出增加、本幣貶值**。
📝（第 36 張）「在 E′ 點 $i < i_f$ → 投資人賣本幣買外幣 → 本幣貶值，本國貨變便宜 → 國內需求增加，NX↑ → IS 向右」

## 三、Mundell（1963）結論（第 37 張）
| | 貨幣政策 | 財政政策 |
|---|---|---|
| 固定匯率 | **完全無效** | **產出效果最大** |
| 浮動匯率 | **產出效果最大** | **完全無效** |

詳見[開放經濟下的政策效果](../synthesis/%E9%96%8B%E6%94%BE%E7%B6%93%E6%BF%9F%E4%B8%8B%E7%9A%84%E6%94%BF%E7%AD%96%E6%95%88%E6%9E%9C.md)。

## 直覺
- 完全資本移動下，利率被世界利率「釘死」在 $i_f$。
- 固定匯率：央行要守匯率，就必須放棄控制貨幣供給 → 貨幣政策被抵銷。
- 浮動匯率：匯率會自動調整 → 財政擴張帶來的升值把需求抵銷掉。

## 常見考點與誤解
- 固定匯率下「貨幣政策無效」不是因為央行不想做，而是**為了守匯率被迫反向操作**。
- 浮動匯率下財政擴張的「排擠」是透過**升值**排擠淨出口，不是透過利率排擠投資。
- 結論依賴「完全資本移動」假設。
