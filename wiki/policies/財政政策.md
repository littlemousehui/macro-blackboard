# 財政政策

> 健康檢查後新增的跨章整合頁：內容全部取自既有 wiki 頁。

## 工具
- **政府購買 $G$**：直接增加[總需求](../concepts/%E7%B8%BD%E9%9C%80%E6%B1%82.md)
- **租稅與移轉支付**：改變可支配所得，再透過消費影響需求（[凱因斯消費函數](../models/%E5%87%B1%E5%9B%A0%E6%96%AF%E6%B6%88%E8%B2%BB%E5%87%BD%E6%95%B8.md)）
- **消費券**：直接發錢給民眾消費（[消費券](%E6%B6%88%E8%B2%BB%E5%88%B8.md)）

## 封閉經濟：財政擴張的傳導
$G$↑ → IS 右移 → 產出↑、利率↑（[IS-LM 模型](../models/IS-LM%20%E6%A8%A1%E5%9E%8B.md)；表格為補充）

## 開放經濟：效果取決於匯率制度（完全資本移動）
| | 財政擴張的效果 | 原因 |
|---|---|---|
| 固定匯率 | ✅ **最有效** | 利率高於 $i_f$ → 資本流入、升值壓力 → 央行釋出本幣 → LM 也右移 → 產出再增加 |
| 浮動匯率 | ❌ **無效** | 資本流入 → 本幣升值 → 淨出口↓ → IS 被推回原位 |
（[Mundell-Fleming 模型](../models/Mundell-Fleming%20%E6%A8%A1%E5%9E%8B.md)、[開放經濟下的政策效果](../synthesis/%E9%96%8B%E6%94%BE%E7%B6%93%E6%BF%9F%E4%B8%8B%E7%9A%84%E6%94%BF%E7%AD%96%E6%95%88%E6%9E%9C.md)；📝「在浮動匯率無效」「政府撒錢 → i > i_f → 外資湧入 → 本幣升值」）

## 發錢真的會讓人多花嗎？消費理論的看法
| 理論 | 一次性發錢的效果 |
|---|---|
| 凱因斯 | MPC 高 → 效果大 |
| 生命週期／恆常所得 | 暫時所得，MPC ≈ 0.017 → 效果小 |
| 流動性限制 | 對借不到錢的家庭效果較大 |
實證：台灣 2009 年消費券只有約 1/4 用於計畫外消費；南韓 2020 年只有 36% 家庭增加支出。（[消費券](%E6%B6%88%E8%B2%BB%E5%88%B8.md)、[消費理論比較](../synthesis/%E6%B6%88%E8%B2%BB%E7%90%86%E8%AB%96%E6%AF%94%E8%BC%83.md)）
