# 匯率制度（固定 vs 浮動）

## 兩種制度
| | 固定匯率（📝「固定匯率」） | 浮動（彈性）匯率（📝「彈性匯率制度」） |
|---|---|---|
| 定義 | 央行以固定價格買賣本國貨幣（📝「本國貨幣和另一種貨幣維持一個固定的兌換比率」） | 央行讓匯率調整，使外幣供需相等（📝「央行允許匯率波動，匯率高低完全由外匯市場供給和需求決定」） |
| 央行角色 | 必須[干預](../concepts/%E5%A4%96%E5%8C%AF%E5%B9%B2%E9%A0%90%E8%88%87%E5%A4%96%E5%8C%AF%E5%AD%98%E5%BA%95.md)，持有外匯存底 | 不干預（stands aside） |
| 國際收支 | 缺口由央行干預補足 | 自動 $BP = 0$ |
| 貨幣供給 | 與國際收支連動 | 可自由決定，與國際收支無自動連動（📝） |
（[第13章 國際連結](../sources/%E7%AC%AC13%E7%AB%A0%20%E5%9C%8B%E9%9A%9B%E9%80%A3%E7%B5%90.md) 第 9–12、30 張）

## 固定匯率如何維持（第 9 張）
- 沒人會用高於固定價格買美元（可以用固定價格買到）
- 沒人會用低於固定價格賣美元（可以用固定價格賣出）
→ 市場價格等於固定匯率

## 浮動匯率的例子（第 12 張）
- 日圓兌美元原本 0.86 美分／日圓
- 日本對美出口增加 → 美國人要付更多日圓給日本出口商（📝「日元需求增加」）
- 日本央行不干預 → 匯率可能升到 0.90 美分／日圓
- 日本商品以美元計變貴 → 美國人對日本商品的需求下降（📝「價格↑，需求↓」）

## 政策效果（完全資本移動下）
| | 貨幣政策 | 財政政策 |
|---|---|---|
| 固定匯率 | 無效 | 最有效 |
| 浮動匯率 | 最有效 | 無效 |
見[Mundell-Fleming 模型](../models/Mundell-Fleming%20%E6%A8%A1%E5%9E%8B.md)、[開放經濟下的政策效果](../synthesis/%E9%96%8B%E6%94%BE%E7%B6%93%E6%BF%9F%E4%B8%8B%E7%9A%84%E6%94%BF%E7%AD%96%E6%95%88%E6%9E%9C.md)。
