# 黃金法則（Golden Rule）

## 定義
讓**穩態人均消費 $c^*$ 最大**的儲蓄率與資本水準。$c^*$ 是社會福利的重要指標。（[第3章 成長與累積](../sources/%E7%AC%AC3%E7%AB%A0%20%E6%88%90%E9%95%B7%E8%88%87%E7%B4%AF%E7%A9%8D.md) 第 30 張）

| 名稱 | 符號 |
|---|---|
| 黃金法則儲蓄率（golden rule savings rate） | $s_g$ |
| 黃金法則人均資本（golden rule capital per capita） | $k_g^*$ |
| 黃金法則人均消費（golden rule consumption per capita） | $c_g^*$ |

## 為什麼存在最適儲蓄率（第 29 張）
人均消費 $c = y - sy = (1-s)y$。儲蓄率 $s$ 經由兩個方向相反的管道影響 $c^*$：
1. $s$↑ → 每人儲蓄增加 → 當下消費的比例下降 → $c^*$↓
2. $s$↑ → 人均資本 $k$↑ → $y$↑ → $c^*$↑

兩股力量互相拉扯，所以存在一個讓 $c^*$ 最大的 $s$。

## 推導（第 31–32 張）
政府的最適化問題：
$$ \max_{s}\; c = (1-s)f(k^*) \quad \text{s.t.}\quad sf(k^*) = (n+\delta)k^* $$
限制式要求必須處在[穩態](%E7%A9%A9%E6%85%8B.md)。

因為 $s$ 和 $k^*$ 一一對應，把限制式代入目標式，改成對 $k^*$ 求最大：
$$ \max_{k^*}\; c = f(k^*) - (n+\delta)k^* $$

一階條件（對 $k^*$ 微分令其等於 0）：
$$ \boxed{f'(k_g^*) = MPK = n + \delta} $$

## 直覺
左邊 $MPK$ 是「多一單位資本能多生產多少」；右邊 $n+\delta$ 是「多維護一單位資本要付出多少成本」（📝 課堂筆記）。
- $MPK > n+\delta$：多累積資本划算，應該提高 $s$。
- $MPK < n+\delta$：資本太多了，維護成本吃掉產出，降低 $s$ 反而能增加消費。

## 圖形（第 33 張）
在 $f(k)$ 上找**切線斜率等於 $n+\delta$** 的點，也就是和 $(n+\delta)k$ 平行的那一點，對應的就是 $k_g^*$。這一點上 $f(k)$ 和 $(n+\delta)k$ 的垂直距離最大，這段距離就是 $c_g^*$。政府把儲蓄率調到 $s_g$，讓 $s_g f(k)$ 剛好在 $k_g^*$ 和 $(n+\delta)k$ 相交（點 $Q_g^*$）。

```
 y │                  切線斜率 = n+δ
   │              ‥‥‥／‾‾‾‾‾ f(k)
   │          ‥‥／┆
   │       _-‾    ┆ ← c_g*（最大垂直距離）
   │     /        ┆      ／ (n+δ)k
   │    /       __Q_g*‾‾‾ s_g f(k)
   │   /   __--‾／
   │  / _-‾ ／
   │ /-‾ ／
   │/_／
   └──────────────┼────────── k
                  k_g*
```

## 常見誤解
- ❌「儲蓄率愈高，人民愈富裕」→ ✅ 產出 $y$ 會更高，但**消費**不一定更高；超過 $s_g$ 之後 $c^*$ 會下降。
- 黃金法則條件是 $MPK = n+\delta$，不是 $MPK = 0$。
- ⚠️ 第 31 張說政府可「透過貨幣政策影響利率」來調整儲蓄率，這在長期模型中不嚴謹，見 [第3章 成長與累積](../sources/%E7%AC%AC3%E7%AB%A0%20%E6%88%90%E9%95%B7%E8%88%87%E7%B4%AF%E7%A9%8D.md) 的疑問欄。
